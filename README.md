# Lista de Exercícios em JavaScript🚀

Este repositório contém uma lista de exercícios resolvidos em **JS**, abordando conceitos essenciais como **loops, condicionais e cálculos matemáticos**.

## 📌 Exercícios Implementados

1️⃣ **Classificação do IMC** - Calcula o IMC do usuário e exibe sua classificação. O programa permite várias execuções sem precisar reiniciar.  

2️⃣ **Faixa Etária** - Classifica a faixa etária de várias pessoas e exibe um contador para cada categoria.  

3️⃣ **Cálculo de Frete** - Calcula o valor do frete com base na quantidade de peças, região de destino e distância percorrida.  

4️⃣ **Folha de Pagamento** - Simula um sistema de folha de pagamento, calculando salários com base no turno e categoria do funcionário.  

5️⃣ **Média Ponderada** - Calcula a média final dos alunos com pesos específicos para cada nota e exibe a classificação final.
